# Snake Game

A classic Snake game implemented in HTML, CSS, and JavaScript.

## Gameplay

The player controls a snake on a 2D grid. The goal is to eat food pellets that appear on the screen. Eating a pellet increases the snake's length and the player's score. The game ends if the snake collides with the walls or itself.

## Features

*   **Scoring System:** Includes a high score that is saved in the browser's local storage.
*   **Pet System:** Players can buy eggs to hatch pets that provide a score multiplier.
*   **Rebirth System:** Allows players to reset their progress for a permanent score multiplier.
*   **Autopilot and Auto-clicker Modes:** For automated gameplay.
*   **Speed Controls:** Adjust the game's difficulty.
*   **Mobile-Friendly Controls:** Play on the go!

## How to Play

1.  Clone this repository or download the files.
2.  Open the `index.html` file in your web browser.

That's it! No build process is required.

## Development

The project is built with plain HTML, CSS, and JavaScript.

*   `index.html`: The main HTML file that defines the structure of the game's UI.
*   `style.css`: The stylesheet that defines the visual appearance of the game.
*   `script.js`: The JavaScript file that contains all the game logic.

The JavaScript code is written in a procedural style and is not bundled or minified. It uses the Canvas API to render the game and interacts with the DOM to update the score and other UI elements.
